# 🗺️ MAPA COMPLETO — DALEH FITWEAR

Este documento é o **mapa geral do projeto DALEH FITWEAR**.

Use quando esquecer onde alguma coisa está ou quando surgir algum problema.

---

# 1. COMO O PROJETO FUNCIONA

A DALEH está dividida em 3 partes principais:

### HTML

É a **estrutura**.

Exemplo:

* textos
* botões
* títulos
* menu
* áreas da página
* modal
* carrinho

### CSS

É a **aparência**.

Exemplo:

* cores
* tamanhos
* posições
* fontes
* espaçamentos
* responsividade
* animações

### JAVASCRIPT

É o **funcionamento**.

Exemplo:

* abrir modal
* trocar foto
* adicionar ao carrinho
* calcular quantidade
* filtrar produtos
* abrir menu mobile

# 3. INDEX.HTML — O PONTO DE PARTIDA

📄 `index.html`

É a **base principal do site**.

Ele conecta HTML + CSS + JavaScript.

Dentro dele existem espaços como:

```html
<div id="header"></div>
<div id="hero"></div>
<div id="categorias"></div>
<div id="produtos"></div>
<div id="sobre"></div>
<div id="footer"></div>
```

Depois o JavaScript coloca cada arquivo HTML nesses espaços.

### Procure o index.html quando:

* precisar adicionar um CSS;
* adicionar um JavaScript;
* adicionar biblioteca;
* alterar título da aba;
* alterar meta description;
* criar espaço para uma nova seção.

---

# 4. COMPONENTES.JS — O MONTADOR DO SITE

📄 `js/componentes.js`

Este arquivo **monta a página**.

Ele busca os HTMLs separados:

```text
header.html
hero.html
categorias.html
produtos.html
sobre.html
footer.html
...
```

e coloca cada um no lugar correspondente do `index.html`.

### Fluxo:

```text
index.html
     ↓
componentes.js
     ↓
sections/
     ↓
página montada
```

### Se uma seção inteira desaparecer:

Primeiro verifique:

📄 `componentes.js`

Depois verifique se o arquivo realmente existe dentro de:

📁 `sections/`

# 15. GLOBAL.CSS — CUIDADO

🎨 `css/css/global.css`

É o CSS geral.

Pode controlar:

* Cores principais
* Fontes
* Body
* Reset
* Variáveis
* Configurações usadas em várias seções

### Regra:

Se quiser mudar **UMA seção**, procure o CSS daquela seção.

Se quiser mudar algo **NO SITE INTEIRO**, procure:

`global.css`

⚠️ Tenha cuidado ao alterar esse arquivo porque uma mudança pode afetar várias áreas.

# 19. REGRA PARA ALTERAR SEM QUEBRAR

Antes de modificar qualquer coisa:

### PASSO 1

Descubra qual seção apresenta o problema.

Exemplo:

`Modal`

### PASSO 2

Pergunte:

**É estrutura?**

→ HTML

**É aparência?**

→ CSS

**É funcionamento?**

→ JavaScript

### PASSO 3

Altere apenas o arquivo necessário.

### PASSO 4

Salve.

### PASSO 5

Atualize o navegador.

### PASSO 6

Teste novamente.

---

# 20. NÃO ALTERE VÁRIAS COISAS DE UMA VEZ

Exemplo:

Se o botão estiver com a cor errada:

❌ Não mexa no HTML + CSS + JavaScript.

Procure apenas:

🎨 CSS

Isso facilita descobrir erros.

---

# 21. USE O CONSOLE DO NAVEGADOR

Se alguma funcionalidade parar:

Pressione:

`F12`

Depois:

`Console`

Erros JavaScript normalmente aparecem em vermelho.

Isso pode ajudar a descobrir:

* arquivo não encontrado;
* função inexistente;
* variável errada;
* elemento HTML não encontrado.

# 23. A REGRA MAIS IMPORTANTE

Quando tiver dúvida, pense:

## HTML

**O que é?**

## CSS

**Como aparece?**

## JAVASCRIPT

**O que faz?**

Exemplo:

**"Quero trocar o texto ADICIONAR AO CARRINHO."**

→ HTML

**"Quero deixar o botão dourado."**

→ CSS

**"Clico no botão e não adiciona."**

→ JavaScript
