# DALEH FITWEAR — GUIA DOS ARQUIVOS HTML

Este arquivo serve como um mapa para lembrar **onde alterar cada parte do site**.

REGRA SIMPLES:

**HTML = o que existe na página.**
**CSS = aparência da página.**
**JavaScript = funcionamento da página.**

---

## 📁 index.html

**O que é:**
É o arquivo principal do site. É como se fosse a base que junta todas as outras partes.

**Aqui ficam:**

* Configurações principais da página
* Título da aba do navegador
* Meta description
* Fontes do Google
* Font Awesome
* Carregamento dos arquivos CSS
* Espaços onde os componentes HTML serão carregados
* Carregamento dos arquivos JavaScript

**Mexa aqui quando quiser:**

* Alterar o título da página
* Alterar a descrição do site para o Google
* Adicionar um novo arquivo CSS
* Adicionar um novo arquivo JavaScript
* Criar uma nova seção principal
* Adicionar fontes ou bibliotecas externas

**IMPORTANTE:**
Normalmente não é aqui que você altera produtos, textos das seções ou aparência.

# 💡 LEMBRETE

Se o problema for:

**"Quero mudar o TEXTO ou adicionar/remover alguma coisa."**
→ procure primeiro o **HTML**.

**"Quero mudar COR, TAMANHO, POSIÇÃO ou ESPAÇAMENTO."**
→ provavelmente está no **CSS**.

**"Cliquei e não funciona / carrinho não calcula / modal não abre."**
→ provavelmente está no **JavaScript**.

HTML = **estrutura**
CSS = **visual**
JavaScript = **funcionamento**
