DALEH FITWEAR — GUIA DOS ARQUIVOS JAVASCRIPT

Este arquivo serve para lembrar onde alterar o funcionamento da DALEH FITWEAR.

REGRA PRINCIPAL

HTML = o que existe
CSS = como aparece
JavaScript = o que acontece

Exemplos:

Clicou no produto e precisa abrir uma janela?
→ JavaScript

Clicou no + e precisa aumentar a quantidade?
→ JavaScript

Adicionou produto e precisa atualizar o carrinho?
→ JavaScript

Selecionou uma categoria e precisa filtrar produtos?
→ JavaScript

📁 js/
componentes.js
O que é

É um dos arquivos mais importantes para a organização do projeto.

Ele é responsável por carregar os vários arquivos HTML separados e colocá-los dentro da página principal.

Atualmente ele trabalha com componentes como:

header.html
hero.html
categorias.html
produtos.html
sobre.html
produto-modal.html
carrinho.html
footer.html
Exemplo

No index.html temos:

<div id="footer"></div>

E no componentes.js:

footer: "sections/footer.html"

O JavaScript pega o conteúdo de:

sections/footer.html

e coloca dentro de:

<div id="footer">

É por isso que conseguimos manter o projeto dividido em vários arquivos.

Mexa aqui quando:
Criar uma nova seção HTML
Alterar o caminho de um componente
Renomear algum arquivo HTML
Um componente não estiver carregando
Aparecer erro de fetch() relacionado às sections
⚠️ IMPORTANTE

Se você criar futuramente:

depoimentos.html

provavelmente precisará adicionar esse componente aqui também.

produtos.js
O que é

É o arquivo relacionado aos produtos da loja.

É um dos primeiros lugares para procurar quando precisar alterar informações dos produtos.

Aqui podem estar dados como:

ID
Nome
Categoria
Preço
Descrição
Imagem
Várias imagens
Tamanhos
Cores
Estoque
Produto novo
Mais vendido

Também pode conter funções responsáveis por mostrar os produtos na tela e trabalhar com os filtros.

Exemplo de estrutura

Você poderá encontrar algo parecido com:

{
    id: 1,
    nome: "Conjunto Essencial",
    categoria: "Conjuntos",
    preco: 149.90,
    imagem: "...",
    estoque: 8
}
Mexa aqui quando:

Quero trocar o preço de um produto.
→ produtos.js

Quero mudar o nome do produto.
→ produtos.js

Quero adicionar as fotos que ainda estão faltando.
→ procure primeiro produtos.js

Quero alterar estoque.
→ produtos.js

Quero cadastrar um novo produto.
→ provavelmente produtos.js

Quero alterar tamanhos ou cores disponíveis.
→ provavelmente produtos.js

Filtro TODOS / CONJUNTOS / TOPS etc. não funciona.
→ procure primeiro produtos.js

É diferente de:

produto-modal.html → estrutura

produto-modal.css → aparência

produto-modal.js → funcionamento

Descobrir qual produto foi clicado
Mostrar dados do produto
Mostrar preço
Mostrar descrição
Mostrar estoque
Mostrar tamanhos
Mostrar cores
Mostrar imagem
Criar miniaturas
Trocar imagens
Seta anterior
Próxima imagem
Selecionar tamanho
Selecionar cor
Aumentar quantidade
Diminuir quantidade
Impedir quantidade acima do estoque
Adicionar produto ao carrinho
Fechar o modal

🧠 COMO DESCOBRIR ONDE ESTÁ O PROBLEMA

Faça estas três perguntas:

1. O elemento nem existe?

Exemplo:

"Quero adicionar um botão novo."

→ HTML

2. Existe, mas está feio ou no lugar errado?

Exemplo:

"O botão está muito grande."

→ CSS

3. Está bonito, mas quando clico não acontece nada?

Exemplo:

"Clico em adicionar ao carrinho e não funciona."

→ JavaScript

🛍️ EXEMPLO COMPLETO — PRODUTO
