Criar uma variável de cor nova

📱 RESPONSIVIDADE

Quando algo estiver bonito no computador, mas ruim no celular, procure dentro do CSS correspondente por:

@media

Por exemplo:

@media (max-width: 600px) {
    ...
}

Isso significa aproximadamente:

"Quando a tela tiver até 600px, use estas configurações."

Então:

Modal ruim no celular?
→ produto-modal.css → procure @media

Produtos ruins no celular?
→ produtos.css → procure @media

Header ruim no celular?
→ header.css → procure @media

🧠 REGRA PARA NÃO SE PERDER

Antes de alterar alguma coisa, pergunte:

Quero mudar O QUE ESTÁ ESCRITO?

Provavelmente → HTML

Quero mudar COMO ESTÁ APARECENDO?

Provavelmente → CSS

Quero mudar O QUE ACONTECE QUANDO CLICO?

Provavelmente → JavaScript

⚠️ CUIDADO ESPECIAL COM global.css

global.css pode afetar o projeto inteiro.

Por isso:

Mudança específica em uma seção
→ procure o CSS daquela seção.

Mudança que quero aplicar ao site inteiro
→ procure global.css.

Isso ajuda a evitar alterar uma coisa e quebrar outras partes da DALEH.
